Terbuka, tapi dijaga

Karena dibuka untuk publik, atlys dijaga seperti layanan yang memang akan diserang. Tiga mekanisme utamanya:

SSRF guard 8 lapis

Setiap request keluar melewati 8 lapis validasi sebelum dieksekusi di worker produksi.

Key disimpan sebagai hash

Server hanya menyimpan hash dari api key anda. Key utuh tampil satu kali dan tidak pernah dikirim lewat email.

Ditijau manusia

Setiap pendaftaran melewati captcha buatan sendiri lalu ditinjau manual. Tidak ada key yang aktif otomatis.

Mulai dari yang gratis

Semua tingkat akses gratis, selamanya. Bedanya cuma di kuota dan cara masuknya.
