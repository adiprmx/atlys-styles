Dijaga serius, tetap terbuka

Atlys terbuka untuk publik, jadi keamanannya dibangun seperti layanan yang memang akan diserang.

SSRF guard 8 lapis

Setiap request keluar melewati 8 lapis validasi sebelum dieksekusi di worker produksi.

Key disimpan sebagai hash

Server hanya menyimpan hash dari api key. Key utuh tampil satu kali dan tidak pernah dikirim lewat email.

Review manual

Pendaftaran melewati captcha proof of work buatan sendiri lalu ditinjau manusia. Tidak ada key aktif otomatis.

Mulai dalam tiga langkah

Tidak ada paywall dan tidak ada kartu kredit. Alurnya memang sesederhana ini.

LANGKAH 01

Isi form pendaftaran

Nama, email yang aktif, dan tujuan pemakaian. Email sekali pakai otomatis ditolak sistem.

LANGKAH 02

Lewati captcha, lalu ditinjau

Captcha proof of work menyaring bot, setelah itu pengajuan anda dibaca dan ditinjau manual.

LANGKAH 03

Key aktif, langsung pakai

Key tampil satu kali di layar untuk anda simpan. Sesudahnya tinggal panggil endpoint pertama anda.

Tiga tingkat akses

Semua tingkat gratis. Bedanya di kuota dan cara masuknya.
