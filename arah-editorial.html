04

Coba tanpa daftar

Demo publik memakai satu endpoint contoh. Respons di samping dipangkas agar ringkas.

GET /v1/demo/info/news adalah satu-satunya demo publik. Hasilnya berbentuk envelope yang sama dengan endpoint data: status, creator, result, meta.

curl "https://api.atlys.my.id/v1/demo/info/news?limit=2"

Buka dokumentasi

{
  "status": "ok",
  "creator": "Atlys",
  "result": {
    "items": [
      {
        "id": "demo-n1",
        "title": "Contoh Berita Satu: Judul Ilustratif Untuk Demo"
      }
    ]
  }
}

Respons dipangkas untuk tampil ringkas. Ini data demo, bukan data asli. Data asli tersedia setelah Anda masuk dan memakai API key.
